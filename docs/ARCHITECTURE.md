# Как устроено

## Конвейер одного выпуска

1. **Сценарий** — Claude пишет `scenario.json` и `publish.json` (в чате, пачками по 7).
   Каждая сцена: `prompt` (что на кадре), `speaker`, `text` (*звёздочки* = выделение), `mode` (`salon` / `memory`).
2. **Кадры** — формула стайлгайда: сцена с паспортом героя (`{PALYCH}`, `{VALYA}`, `{KNIGHT}`, `{SALON}`) + БАЗА А (3D) или БАЗА Б (акварель) + негатив.
   `mv.py prompts` собирает полные промпты в `prompts.txt` для Шедеврума; `mv.py images` генерирует через YandexART (9:16),
   основной вариант — в `img/`, запасные — в `img/_variants/`.
3. **Озвучка** — SpeechKit, свой голос на персонажа (`tts.voices`). Длина сцены = длина реплики + пауза.
   Можно подложить свои записи: поле `audio` у сцены.
4. **Монтаж** — `mv.py build`: наезд камеры на кадр, слои оформления (табло, хук 0–2 с, билетик, субтитры кусками по времени),
   для воспоминаний — страница книги с акварелью и переход через кремовую вспышку, концовка с часами «????», музыка.
5. **Публикация** — `mv.py publish`: VK через `video.save`, для Rutube — текстовый пакет.

## Файлы выпуска
```
episodes/ep01_rycar/
  scenario.json   сцены
  publish.json    название, описание, хештеги, закреп
  prompts.txt     полные промпты (создаётся командой prompts)
  img/            кадры
  audio/          музыка, эффекты, свои записи (необязательно)
  output/         ep01_rycar.mp4, rutube.txt
```

## Решения и ограничения
- **Проверка человеком перед публикацией** — нейросеть иногда портит руки и лица; `publish` не запускается автоматически.
- **Единый персонаж** держится неизменяемыми паспортами и базами; удачный кадр Палыча — эталон для сверки.
- **Надписи** (табло, имена, подписи) — только в монтаже, не в генераторе.
- **VK Клипы**: загрузка идёт как видео сообщества; попадёт ли ролик в Клипы, решает VK — проверить на первом выпуске.
- **Rutube**: открытого API загрузки для авторов нет → ручная загрузка или сервис автопостинга (Postmypost).
- **Лицензии**: для монетизации — платные тарифы генераторов (без водяных знаков) и музыка с коммерческой лицензией.
- **Пока упрощено** относительно стайлгайда: переход в воспоминание — вспышка 0,6 с без блика в очках, переворота страницы и звуков.
- Позже: n8n/планировщик для ежедневного запуска, когда ритм устоится.
