# Глобус времени — заставка и концовка

Векторный движок для «Маршрутки времени»: 10 обликов планеты, латунное кольцо-циферблат, ПАЗ на орбите,
пиксельное табло года. Стайлгайд и раскадровки — в холсте (раздел «Глобус времени»).

## Установка (один раз)
```
pip install playwright numpy
playwright install chromium
```
Нужен ffmpeg (он уже стоит для mv.py).

## Заставка 0:02–0:04 (2,5 с, 1080×1920, 30 к/с, со звуком)
```
python intro.py --from-look 10 --to-look 8 --year 1876 --lon -71 --lat 42.4 --out intro_ep09.mp4
```
- `--from-look` — облик прошлого выпуска (по умолчанию 10, «сегодня»)
- `--to-look` — облик эпохи остановки (строка «глобус: облик N» в сценарии)
- `--year` — год на табло; до н. э. — отрицательный (`--year -3700`), миллионы лет — тоже (`--year -200000000`)
- `--lon`, `--lat` — место остановки (долгота, широта), туда вспыхивает точка и ныряет камера
- `--keyframes 0,30,60` — дополнительно сохранить эти кадры PNG

## Концовка 0:56–0:59 (3 с): часы → глобус «????» → силуэт следующего
```
python intro.py --mode ending --from-look 8 --silhouette monk --out ending_ep09.mp4
```
Сейчас в коде один силуэт (`monk`). Дальше силуэт берётся из картинки: генерируем следующего пассажира
в полный рост на кремовом фоне (промпт «Силуэт» в `claude/design/frames_routeNN.md`), программа заливает фигуру
сливовым #2E2433 и даёт абрикосовый контур. Текст «Куда поедем дальше?», кнопку и «За проезд — подпиской!»
накладывает mv.py поверх последней секунды (табло к этому моменту гаснет).
